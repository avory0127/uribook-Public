# 우리북 · 가족 앨범

사진을 넣으면 찍은 날짜순으로 정리하고 보정해서 월간·연간 가족 포토북을 만들어 주는 아이폰 홈 화면 앱(PWA)입니다.

## 아이폰에 설치하기

1. 아이폰 **Safari**로 앱 주소를 엽니다: `https://avory0127.github.io/uribook-Public/`
2. 아래쪽 **공유** 버튼을 누릅니다 (네모에서 화살표가 위로 나온 아이콘).
3. **홈 화면에 추가**를 고른 뒤 **추가**를 누릅니다.

이제 홈 화면의 **우리북** 아이콘으로 앱처럼 열립니다. 한 번 열고 나면 인터넷이 없어도 쓸 수 있어요.

## 할 수 있는 것

- 사진을 넣으면 촬영 날짜를 읽어 월간(날짜별) 또는 연간(달마다 챕터) 앨범을 자동으로 구성
- 자동 보정(노출·화이트밸런스·대비), 필터 10가지, 직접 보정 슬라이더
- 인물 보정: 얼굴 주변 피부 결·밝기·홍조, 얼굴이 잘리지 않게 자르기
- 한 페이지 1~12장, 테마 24가지, 컨셉 12가지
- 인쇄용 PDF(300dpi, 재단 여백 3mm, TrimBox) 또는 페이지별 JPG
- 공유 창으로 ‘파일에 저장’, 카카오톡, AirDrop, 프린트
- 내 책장: 만든 책을 휴대폰에 보관하고 다시 넘겨보기

## 개인정보

사진은 휴대폰 안에서만 처리되고 어디에도 올라가지 않습니다. 만들던 책과 내 책장은 이 휴대폰의 앱 저장 공간에만 보관됩니다.

## 업데이트하는 방법

파일을 고친 뒤 `sw.js`의 `VERSION` 값을 하나 올려서(`uribook-v2` 등) 올리면, 앱을 열 때 ‘새 버전이 준비됐어요’ 알림이 뜹니다.
